# 窝头RJの存钱罐

只供个人使用的离线资产快照工具。它是一个 macOS / Windows 桌面应用，不含账号、云端同步、分析埋点、自动更新或任何外部请求。

## 最重要的数据规则

- 第一次启动会选择一个**由你自己管理的本地文件夹**。资产数据不存浏览器缓存，也不放在安装包目录。
- 主数据文件为「窝头RJの存钱罐.json」；每次保存一笔快照时，会再生成「备份/YYYY-MM-DD_HHmmss.json」。
- 备份只保留最近 30 份。主数据无法读取时，应用会依次尝试最近的备份并明确提示恢复结果。
- 平台、产品和资产类型的变更立即原子写入磁盘；保存失败会在页面顶部红色提示，绝不会静默忽略。
- 更换数据目录时，应用会先复制主数据和备份到新目录，并**保留旧目录原件**作为额外安全副本。
- 卸载、重装或清理应用缓存不会删除你选定数据目录中的文件。重新安装后选择原来的数据文件夹即可继续使用。

建议：数据目录放在你平时备份的个人文件夹或加密磁盘中；每隔一段时间导出一次 JSON 到另一个磁盘。

## 完整操作流程

### 1. 首次安装与数据目录

1. 在上方表格中下载适合自己电脑的安装包；不要下载 `Source code (zip)`。
2. Windows 双击 `.exe` 完成安装或启动；Mac 打开 `.dmg`，把 App 拖到“应用程序”。
3. 第一次打开时，点击「选择数据文件夹」，选一个你长期保留、自己能找到的本地文件夹，例如“文档/窝头RJ存钱罐数据”。
4. App 会在其中创建主数据文件 `窝头RJの存钱罐.json`，以后所有记录和自动备份都在这里。不要把这个文件夹放在安装包目录或临时下载目录。

> Mac 若提示“无法验证开发者”，请到“系统设置 → 隐私与安全性”点击“仍要打开”。这不会改变数据位置，也不会上传任何数据。

### 2. 先建立你的资产清单

打开左侧的「管理」，按下面顺序设置一次即可：

1. **平台**：点击「新增平台」，填写钱放在哪里，例如支付宝、微信、招商银行、天天基金、券商 App、现金。
2. **产品**：点击平台行右侧的「加产品」，填写具体项目，例如余额宝、零钱通、活期账户、某只基金或信用卡。
3. **资产类型**：产品需要选择一个类型。内置有活钱、稳健、基金投资、高风险、负债；可以改名称、改颜色、排序，也可以新增未使用的类型。
4. 每个产品默认「计入总资产」。如果只是想记录但不想让它参与净资产合计，取消这个开关即可。

这里没有“归档”功能：平台、产品和类型会一直保留，避免过去的历史记录出现缺失。若某个产品以后不用了，日常记录时填 `0` 即可；不要删除仍被历史记录使用的类型。

### 3. 日常记一笔

1. 打开「记一笔」，日期默认是今天，可改为任意要记录的日期。
2. 页面按平台分组显示产品；每个金额输入框会自动带入上一次记录的值，只改有变化的项目即可。
3. 用键盘 `Tab` 可以快速跳到下一个输入框；「全部沿用上次」可重新填回上一条的所有金额；「折叠 / 展开」可收起平台区块。
4. 底部会实时显示本次净资产，以及相对上次记录的变化金额和百分比。
5. 可填写选填备注，例如“发工资”“还信用卡”“基金调仓”，然后点击「保存本次记录」。
6. 如果同一天已经有记录，App 会询问是否覆盖；确认后会保留一份自动备份再写入新数据。

每次保存记录都会立即写入主数据，并生成一份带时间戳的自动备份。若数据文件夹不可写、磁盘异常，或文件被其他程序暂时占用，页面会显示红色错误提示；未写成功的更改不会被当成已保存。

### 4. 查看总览、历史和分析

- **总览**：查看最新净资产、总资产、总负债、与上次变化，以及按平台 / 类型的拆分。
- **历史**：按日期倒序查看全部快照；点「展开」可看到该日每个产品的金额和相对上次的变化；点「删除」会二次确认并先自动备份。
- **分析**：按平台、资产类型或流动性查看当前金额、占比和相较上次的占比变化。分析页只读，不会修改数据。

### 5. 导出近一年记录与完整备份

打开「数据与备份」：

1. **导出近一年 CSV**：导出过去 365 天的全部记录，适合用 Excel 打开、筛选或自己做统计。文件带中文兼容格式。
2. **导出近一年 PDF**：导出过去 365 天的可打印报表。
3. **导出完整 JSON**：导出全部平台、产品、历史记录和设置；这是换电脑、长期保存、恢复数据时最重要的文件。
4. 建议每隔一段时间把完整 JSON 复制到另一个磁盘、网盘同步盘或加密 U 盘。App 会在超过 14 天未导出时显示提醒。

### 6. 换电脑、恢复或更换数据文件夹

**换电脑（推荐）**：

1. 在旧电脑的「数据与备份」点击「导出完整备份」，保存 JSON。
2. 在新电脑安装 App，首次启动选择一个新的本地数据文件夹。
3. 打开「数据与备份 → 导入恢复」，选择刚才的 JSON。App 会先显示其中的记录、平台、产品数量和最新净资产。
4. 确认导入。导入前，当前数据会先自动备份一份。

**直接搬迁数据文件夹**：

1. 在 App 的「数据与备份」点击「更换文件夹」。
2. 选择一个空文件夹；App 会复制主数据和备份到新位置，同时保留旧文件夹的原件，作为额外安全副本。

**主数据损坏时**：App 启动时会自动尝试最近的自动备份，并提示已恢复的备份文件名；如果仍无法读取，可通过「导入恢复」选择你手动导出的 JSON。

### 7. 清空数据

仅在确定不再需要当前主数据时，打开「数据与备份 → 清空所有数据」，输入 `确认清空`。执行前 App 会强制生成自动备份；清空只影响当前数据文件夹的主数据，历史自动备份仍在“备份”子文件夹中。

## 功能

- 平台、产品、资产类型的新增、编辑与排序（不使用归档，确保历史记录完整可见）
- 按平台分组的“记一笔”；自动带入上一条记录的金额
- 同日覆盖二次确认，保存快照后自动备份
- 净资产总览、类型和平台拆分、历史趋势与明细展开
- 平台 / 资产类型 / 流动性多维分析
- JSON 完整备份，以及可导出过去 365 天全部记录的 Excel 兼容 CSV / PDF
- 导入 JSON 前预览记录数、平台数、产品数与最新净资产
- 清空前强制备份并要求输入「确认清空」

## 本地开发

需要 Node.js 20 或更高版本。

    pnpm install
    pnpm start

如果 pnpm 提示 Electron 的构建脚本未获批准，请在项目目录执行：

    pnpm approve-builds

只选择 electron，然后确认。此步骤仅下载 Electron 的本地运行时；应用运行后仍不会联网。

## 打包

在 macOS 上生成 Apple Silicon 和 Intel 的 DMG / ZIP：

    pnpm run dist:mac

在 Windows 上生成 x64 / ARM64 的安装器和便携版：

    pnpm run dist:win

构建结果在 dist/。当前发布版已经提供 macOS（Apple 芯片 / Intel）和 Windows（x64 / ARM64）的四种直接下载附件。后续若需要用 GitHub Actions 自动构建，创建工作流时 GitHub CLI 需要额外具备 `workflow` 权限。macOS 当前会做临时 ad-hoc 签名，避免未签名应用显示“已损坏/被修改”；若要公开分发，仍建议使用 Apple Developer ID 签名并公证。Windows 对外分发也建议配置代码签名证书。

## 数据文件格式

主文件是 UTF-8 JSON，结构版本为 schemaVersion: 1，包含：

- assetTypes：资产类型（含颜色、资产 / 负债角色）
- platforms：平台
- products：产品，关联平台和资产类型
- snapshots：按日期保存的各产品金额
- metadata：创建、保存、导出时间

不要手动编辑正在被应用使用的主文件。若必须手工恢复，请先复制一份，再通过应用的“导入恢复”完成。
